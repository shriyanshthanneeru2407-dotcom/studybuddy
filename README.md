# StudyBuddy — AI-Powered Academic Management Platform

StudyBuddy is a complete, role-based educational workspace designed for students, teachers, and school administrators. Inspired by Notion and Stripe dashboard layouts, it prioritises high usability, readable typography, and clean layouts over distracting neon visuals.

## 🌟 Key Features

*   **Role-Based Dashboards**: Customised tools, stats, and widgets for students, teachers, and administrators.
*   **StudyVision AI**: Side-by-side split screen handwriting digitization tool for answer sheets evaluation (includes drawings remarks annotation and grading sync).
*   **StudyBuddy AI**: Chatbot companion for study plans, Pomodoro timers, active recall prep, and tutor queries (with medical safety disclosures).
*   **Academic Records**: Directory dataset supporting sorting, filtering, editing, and CSV file exports.
*   **Smart Timetable**: Dynamic calendar scheduling with overlap conflict warning notifications.
*   **Goal Planner**: Visually tracked progress bars goals.
*   **School Store**: request cart ordering system for students, and inventory stock managers for admin.
*   **Digital Notice Board**: Broadcast grid for campus announcements with attachments and pinned items.
*   **Theme Engine**: Built-in support for light and dark modes.

---

## 🛠️ Tech Stack & Architecture

*   **Frontend**: Semantic HTML5, CSS3 Custom Properties (CSS variables), Vanilla JavaScript (ES6 Modules).
*   **Custom Chart Library**: Lightweight line, bar, and donut charts built directly on Canvas API (zero external weights).
*   **Responsive**: Fluid grid/flex layouts optimized for desktop, tablet, and mobile displays.
